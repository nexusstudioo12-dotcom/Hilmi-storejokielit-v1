# HILMI STORE

Store & Services - Landing page premium dan profesional dengan integrasi WhatsApp untuk konversi instan.

## Features

- Premium dark UI
- Neon pink design
- Glassmorphism
- Responsive & Mobile-first
- WhatsApp integration
- Auto-filled WhatsApp message
- Service cards
- Floating particles
- SEO ready
- Netlify ready
- Vercel ready
- GitHub ready

## Tech Stack

- HTML5
- CSS3 (Vanilla + CSS Variables)
- Vanilla JavaScript (ES6 Modules)

## Installation

Project ini adalah static site. Tidak perlu build command.
Cukup buka `index.html` di browser atau gunakan ekstensi VS Code **Live Server**.

## Configuration

Edit `js/config.js` untuk mengatur:
- Nomor WhatsApp
- Pesan default
- Channel Link

## WhatsApp System

Sistem Click-to-Chat WhatsApp secara otomatis mem-parsing layanan yang di klik user menjadi URI komponen, lalu mem-bypass form untuk mempercepat UX (langsung diarahkan ke `wa.me`).

Project siap di-deploy secara statis. Lihat [DEPLOYMENT.md](docs/DEPLOYMENT.md).
